# NovaCare — React + Tailwind CSS

پروژه آموزشی خدمات سلامت و بازارچه روزمره با الهام از ایده‌های MyPatientHUB و نمونه‌تصاویر ارسالی. این پروژه نسخه نمایشی (Demo) است؛ اطلاعات، قیمت‌ها، پزشکان و قرارها واقعی نیستند و سفارش یا نوبت به سرویس بیرونی ارسال نمی‌شود.

## اجرای پروژه

1. Node.js نسخه LTS را نصب کن.
2. پوشه پروژه را در VS Code باز کن.
3. در Terminal اجرا کن:

   ```bash
   npm install
   npm run dev
   ```

4. آدرس محلی که Vite چاپ می‌کند در مرورگر باز کن.

برای ساخت نسخه نهایی:

```bash
npm run build
```

## ساختار فایل‌ها

- `src/App.jsx`: پوسته برنامه، مسیریابی صفحات درون برنامه، سبد خرید و پنجره درخواست نوبت.
- `src/components/Sidebar.jsx`: منوی کناری و لینک صفحات.
- `src/components/Topbar.jsx`: جست‌وجوی سراسری و دکمه سبد خرید.
- `src/components/UI.jsx`: اجزای رابط کاربری مشترک.
- `src/components/dashboard/`: بخش‌های مستقل داشبورد (Hero، آمار، دسترسی سریع و پنل‌ها).
- `src/pages/DoctorsPage.jsx`: جست‌وجو و فیلتر پزشکان.
- `src/pages/ClinicsPage.jsx`: فهرست و فیلتر مراکز درمانی.
- `src/pages/PharmacyPage.jsx`: داروخانه‌ها، اطلاعات تماس/مکان و کاتالوگ قابل جست‌وجوی محصولات.
- `src/pages/MarketplacePage.jsx`: فروشگاه مواد غذایی، رستوران، کافه و لبنیاتی؛ ورود به هر فروشگاه و افزودن محصولات به سبد.
- `src/pages/AppointmentsPage.jsx`: برنامه روزانه با ۱۵ نوبت نمونه، پزشکان متعدد و وضعیت‌های متفاوت.
- `src/pages/OtherPages.jsx`: پیام‌ها و بخش سلامت.
- `src/data/mockData.js`: داده‌های نمونه متمرکز برای آسان کردن ویرایش.
- `src/styles.css`: لایه‌های Tailwind و استایل‌های سفارشی.

## تغییرات امن‌تر

هر صفحه در فایل مستقل است. برای اصلاح کارت‌های پزشک، ابتدا `DoctorsPage.jsx` را تغییر بده؛ برای داروخانه `PharmacyPage.jsx`؛ برای فروشگاه‌ها `MarketplacePage.jsx`. داده‌ها را در `src/data/mockData.js` تغییر بده. اجزای مشترک مثل `Topbar.jsx` و `Sidebar.jsx` چندین صفحه را تحت تأثیر قرار می‌دهند.

## امکانات نمایشی

- داشبورد آماری و دسترسی سریع
- فهرست پزشکان با فیلتر تخصص/شهر/جنسیت و مرتب‌سازی
- فهرست کلینیک‌ها و آدرس‌ها
- جست‌وجوی داروخانه و کاتالوگ محصولات با دسته‌بندی و قیمت نمونه
- سبد خرید مشترک بین داروخانه و Marketplace
- چهار فروشگاه نمونه: مواد غذایی، رستوران افغانی، کافه و لبنیاتی/صبحانه
- درخواست نوبت و صفحه زمان‌بندی شامل ۱۵ نوبت نمونه
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
